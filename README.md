# Fish Whut Talks

Big Mouth Billy Bass simulator — paste a YouTube link (or get a random [@HotMakesLive](https://www.youtube.com/@HotMakesLive) episode) and Billy mouths along to the captions.

## Live

GitHub Pages: https://techjeeper.github.io/FishWhutTalks/

## Local

Serve the folder over HTTP (YouTube embeds need a real origin):

```bash
python -m http.server 8765
```

Open http://localhost:8765
